# 范围

用户要求对 ins.itcsdn.com 对应项目进行页面改版、美化和 SEO 优化，已明确授权编码。

- 独立 INS 技术雷达品牌，主站外链。
- 白色与冷灰基底、现有 Indigo 强调色；清晰阅读层级与响应式导航。
- 首页、AI、开源、资讯、工具、关于、404 统一设计。
- 关键词搜索、信源筛选、日期排序、分批加载和无结果清除状态。
- 日期与信源数量来自真实数据，不伪造实时状态或热度。
- 站长收藏保留原始标题链接，不将语义不匹配的旧点评作为新编辑结论呈现。
- 每页独立 SEO、分享封面、JSON-LD、robots、sitemap、RSS、可遍历归档。
- 不修改原始 JSON 数据，不触发采集，不部署或修改 DNS。
