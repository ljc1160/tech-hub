# 计划：tech-hub 推广区块（工具推荐）

## Context

用户希望在 tech-hub 网站中展示客户的微信小程序二维码和描述，用于推广引流。要求：
- 形式隐晦，不像广告，以"工具推荐"为定位
- 不占用独立模块，不打断主页内容流

## 设计决策

- 标签文字：**工具推荐**（最隐晦，不突出）
- 视觉风格：与 `CuratedCard` 同族，左侧 amber 色装饰线，区别于站长精选的 indigo
- **放置位置：关于页（`/about`），数据来源区块之后**
- 实现方式：直接内嵌在 `about/page.tsx`，无需独立 JSON/组件

## 关于页同步调整

- **移除"内容说明"区块**：内容暴露了技术实现细节（GitHub Actions、RSS 等），对普通用户无意义
- **移除底部更新时间说明**：同上

## 验证步骤

1. 将二维码图片放入 `public/sponsors/gh_2bf4a7d2a911_344.jpg`
2. 运行 `npm run dev`，访问 `/about` 确认卡片出现在数据来源下方
3. 确认"内容说明"和更新时间说明已不再显示
